# artven — демо главной страницы

Фронтенд по макету из Figma. Бэкенд полностью замокан (MSW работает прямо в браузере), данные хранятся в `localStorage`.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

Нужен интернет: картинки ленты и результатов грузятся с Unsplash.

## Что попробовать

1. **Шаблон.** Нажмите на карточку в «Ideas for You» или на плитку в «Wishes». Промпт подставится в чат, первое поле `[в скобках]` будет выделено. **Tab** переходит к следующему. Пока поля не заполнены, отправка заблокирована.
2. **Файлы.** Перетащите картинку из Finder в любое место страницы, вставьте её через ⌘V или нажмите `+`. Неподходящие файлы (тип, размер, разрешение, больше 5 штук, второе видео) отклоняются с объяснением.
3. **Генерация.** Отправьте промпт. Стоимость видна до отправки: картинка 1 кредит, видео 4. Когда результат готов, появится уведомление, а на Results — точка. Слова в промпте влияют на результат: *ring*, *sneaker*, *sofa* выбирают предмет, *square*, *vertical*, *wide* — формат.
4. **Лимиты.** На Free можно запустить только 2 генерации одновременно. Если кредитов не хватает, предложат пополнение. Неудачные генерации (около 10%) автоматически возвращают кредиты.
5. **Tools.** Вкладка Tools рядом с Chat: выберите инструмент, и его шаблон откроется в чате.
6. **Smart Search.** Кнопка поиска справа от категорий Wishes. Выберите продуктовый профиль или создайте свой (фото, название, категория) и типы контента, затем нажмите **Find Templates**.
7. **Меню.**
   - Аватар: профиль, подписки (Free ↔ Pro), редактирование аккаунта, история кредитов, выход.
   - После выхода генерация и закладки попросят войти. Кнопка **Continue as Demo User** входит без пароля.
   - **?** — форма поддержки и условия. **⌘K** — поиск по Wishes.
8. **Settings → Demo controls.** Задержка сети, случайные ошибки запросов, доля неудачных генераций, сброс всех демо-данных.

Подробности о стеке, валидации и API — в [README.md](README.md).
